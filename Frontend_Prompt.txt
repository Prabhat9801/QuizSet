You are a senior product architect, UX designer, frontend engineer and SaaS product designer.

Build the COMPLETE FRONTEND of a production-quality B2B2C SaaS platform called:

==================================================
                    KOPI
==================================================

TAGLINE:
"Your Coaching. Your Brand. Your Learning OS."

KOPI is a white-label, multi-tenant, AI-powered digital operating system for coaching institutes.

IMPORTANT:
This is a FRONTEND-ONLY application for now.

There must be NO real backend, NO database server, NO real payment gateway, NO real AI API and NO external authentication dependency.

However, the application must behave like a real fully functional SaaS product by using:

- React state
- Context API where appropriate
- localStorage
- mock service layers
- mock API responses
- realistic seed data
- simulated payments
- simulated AI responses
- simulated notifications
- simulated analytics
- realistic loading/error/empty states

The architecture MUST be backend-ready so that real APIs can replace mock services later without rewriting the UI.

==================================================
2. CORE PRODUCT PRINCIPLE
==================================================

KOPI is NOT simply an online quiz application.

It is:

"Digital Operating System for Coaching Institutes"

Think of the product conceptually like Shopify:

KOPI provides technology.

The coaching institute operates its own branded examination business.

Each coaching institute is a separate tenant.
